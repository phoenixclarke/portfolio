Scenario Simulations Sandbox Environment

Dashboard Development

Business Strategy

Core Business Problem

Most clients utilizing a SaaS fraud solution lacked the resources or domain expertise to effectively optimize complex business rules targeting risky online behaviors. Client Managers needed a way to test and refine these rules without increasing customer friction or impacting production environments.

Outcome

Client-facing analysts had a tool to experiment with different risk rule configurations in a safe, controlled environment, leading to more informed recommendations and reduced implementation risk.

Context

Clients attempting to optimize 50+ business rules targeting risky online behaviors were challenged by the product’s high complexity and quickly-evolving fraud techniques. I proposed a self-serve, near-real-time sandbox environment for clients to run scenario simulations, adjust risk rules, and test channel-specific configuration changes before deploying them in production. Using a Tableau-based prototype to demonstrate each business rule’s configuration options and the measurable impact, this prototype showcased how a future web application could streamline experimentation, reduce implementation risk, and give clients greater control over optimizing their SaaS configurations. This proposed web application established revenue-generating opportunities when sold alongside the product.

Prototype View

Approach

  • Researched the attributes used by the product's API to understand the available endpoints and data features needed to simulate production functionality in an offline data tool.
  • Wrote advanced SQL queries to parse complex JSON payload into data structures that standardized features across multiple versions of the product's API.
  • Staged the parsed data into a Snowflake data warehouse dedicated to analytics enablement.
  • Conducted time series analysis, association rule mining, and prescriptive analysis to refine the calculation logic and fraud outcomes needed in a sandbox environment.
  • Utilized scenario analysis to evaluate the impact of different configuration changes.
  • Developed a Tableau-based prototype that replicated offline scenario modeling within a sandbox environment.
  • Conducted user testing sessions with Client Managers to gather feedback and refine the prototype.
  • Presented the prototype to stakeholders and secured buy-in for further development. Adopted the prototype as the basis for explaining client optimization recommendations.

Note: This is a prototype demonstration of potential web application functionality.
